# HACKED VR

An immersive VR sound design case study exploring how audio communicates tension, guidance, and interaction inside a cybersecurity-themed virtual world.

## Live Demo

🔗 https://hackedvr.vercel.app/

## Project Overview

HACKED VR is an interactive case study built to showcase the design process behind a virtual reality sound design project. The website recreates the project's narrative through an immersive web experience with cinematic transitions, interactive media, and scroll-driven storytelling.

Rather than presenting a traditional portfolio page, the experience walks visitors through the project's context, design framework, production pipeline, technical integration, and reflections.
